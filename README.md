# 🧮 Calculadora Digital Simples  

Uma **calculadora digital** desenvolvida com **HTML, CSS e JavaScript**, permitindo realizar operações matemáticas básicas de forma rápida e intuitiva.  

---

## 📌 **Funcionalidades**  
✅ Interface minimalista e responsiva.  
✅ Operações básicas: **soma (+), subtração (-), multiplicação (*) e divisão (/)**.  
✅ Exibe e calcula expressões digitadas.  
✅ Botão **"C"** para limpar a tela.  

---

## 📂 **Estrutura do Projeto**  
```
📁 calculadora-digital
│── 📄 index.html       # Estrutura da calculadora
│── 🎨 style.css        # Estilização da interface
│── ⚡ script.js        # Lógica da calculadora
│── 📜 README.md       # Documentação do projeto
```

---

## 🚀 **Como Executar**  
1. Faça o download ou clone o repositório.  
2. Abra o arquivo `index.html` no navegador.  
3. Utilize a calculadora para realizar operações matemáticas!  

---

## 🛠 **Tecnologias Utilizadas**  
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização e layout responsivo  
- **JavaScript** → Funcionalidade e cálculos
